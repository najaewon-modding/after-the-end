# After the End - Season 0

**After the End**는 엔더 드래곤 처치 이후의 플레이를 장기적인 진행 요소로 확장하는 Minecraft NeoForge 모드입니다.

Season 0에서는 도시 해금과 Altar 탐험을 중심으로 새로운 지역을 순차적으로 개방하고, 이후 주민 강화, 커스텀 프로필, 개인 건축 공간으로 이어지는 포스트-엔드 진행 구조를 목표로 합니다.

## 개발 환경

- **Minecraft:** 26.1.2
- **NeoForge:** 26.1.2.97
- **Java:** 25
- **Mod Name:** After the End
- **Mod ID:** `njw_after_the_end`
- **Version:** `1.0.0-mc26.1.2`

## Season 0 핵심 구조

현재 구현된 기본 진행 구조는 다음과 같습니다.

`엔더 드래곤 처치 → End 탐험 → 공명 수정 제작 → Altar 활성화 → 다음 도시 해금 → 새로운 도시 탐험`

앞으로 Altar에서 얻는 전용 보상과 주민 강화, 건축 및 장기 플레이 지원 기능을 이 진행 구조에 연결할 예정입니다.

## 도시 시스템

### 도시 영역

각 도시는 오버월드와 네더의 대응 영역을 하나의 도시 단위로 관리합니다.

해금된 도시 영역에서는 정상적으로 활동할 수 있지만, 오버월드와 네더의 해금되지 않은 영역에서는 주요 상호작용이 제한됩니다.

현재 다음 기능이 적용되어 있습니다.

- 여러 도시와 해금 상태 관리
- 오버월드와 네더의 대응 도시 영역 관리
- 도시 밖 블록 설치 및 파괴 제한
- 도시 밖 블록 및 엔티티 상호작용 제한
- 도시 밖 아이템 및 경험치 획득 제한
- 경계 밖 체류 시 경고 후 마지막 정상 위치로 복귀
- 반투명 도시 경계 표시
- 도시 상태와 마지막 정상 위치 저장

### 시작 도시와 월드 생성

싱글플레이 월드 생성 화면에서 시드를 직접 입력하지 않으면, 시작 도시 안에서 기본 게임 진행에 필요한 Stronghold와 Nether Fortress를 이용할 수 있는 시드를 자동으로 탐색합니다.

시드를 직접 지정하거나 전용 서버에서 월드를 생성하는 경우에는 이 자동 탐색이 적용되지 않으며, 현재는 시작 도시 안에 두 구조물이 존재하도록 별도로 보정하지 않습니다.

오버월드에서 엔더의 눈을 사용하면 시작 도시 안에 있는 Stronghold를 향하도록 동작합니다.

### 해금 대기 도시

처음부터 모든 도시를 이용할 수 있는 것은 아닙니다.

월드에는 다음 해금을 위한 도시가 미리 준비되며, 항상 3개의 해금 대기 도시가 유지됩니다. 도시 하나가 해금되면 새로운 해금 대기 도시가 추가로 준비됩니다.

도시 목록에는 모든 해금 대기 도시가 표시되지 않고, 현재 다음으로 해금할 수 있는 도시 하나만 표시됩니다.

### 도시 목록과 이동

기본 `C` 키를 눌러 도시 목록을 열 수 있습니다. 키 설정은 Minecraft 조작 설정에서 변경할 수 있습니다.

도시 목록에서는 다음 정보를 확인할 수 있습니다.

- 현재 확인 가능한 도시 목록
- 도시의 해금 여부
- 오버월드 및 네더 영역

도시 간 이동은 오버월드의 **활성화된 Altar 근처**에서만 사용할 수 있습니다. 이동을 시작하면 잠시 준비 시간이 필요하며, 이동 중 움직이거나 피해를 받거나 주변에 적대적인 몹이 있으면 취소될 수 있습니다.

## Altar

각 도시에는 탐험을 통해 발견할 수 있는 여러 Altar가 생성됩니다.

- 한 도시에는 3개에서 8개의 Altar가 생성됩니다.
- Altar는 크기, 색상, 파손 상태 등이 서로 다를 수 있습니다.
- 한 도시에서 동시에 활성화할 수 있는 Altar는 최대 3개입니다.
- 활성화된 Altar는 도시 간 이동 거점으로 사용할 수 있습니다.
- Altar를 활성화하면 다음 해금 대기 도시가 개방됩니다.

### 공명 수정

Altar 활성화에는 **공명 수정(Resonance Crystal)**이 사용됩니다.

공명 수정은 다음 재료로 제작할 수 있습니다.

- 유리 7개
- 엔더의 눈 1개
- 셜커 코어 1개

셜커 코어는 셜커를 처치하면 획득할 수 있습니다.

공명 수정을 일반 장소에 설치하면 일정 주기로 주변 생명체를 공중부양시키지만, 비활성화된 Altar의 지정된 위치에 설치하면 Altar 활성화에 사용할 수 있는 상태가 됩니다.

### Altar 활성화

현재 Altar 활성화 의식은 `Just Dragon Eggs`에서 기록된 드래곤 알과 공명 수정 4개를 사용합니다.

Altar의 네 위치에 공명 수정을 설치하고 중앙에 기록된 드래곤 알을 놓으면 활성화 의식이 시작됩니다. 의식이 완료되면 해당 Altar가 활성화되고 다음 도시가 해금됩니다.

활성화에 사용한 공명 수정은 소모되며, 기록된 드래곤 알은 의식이 끝난 뒤 다시 회수할 수 있습니다.

## 관리자 기능

현재 도시 관리 기능은 관리자 명령어를 통해 사용할 수 있습니다.

- 도시 생성 및 해금
- 도시 삭제
- 도시 목록과 상세 정보 확인
- 최대 해금 도시 수 설정
- 도시 청크 사전 준비
- Altar 위치 확인

기본 최대 해금 도시 수는 5개입니다. 시작 도시는 삭제할 수 없으며, 플레이어가 내부에 있는 도시는 삭제할 수 없습니다. 최대 도시 수는 현재 해금된 도시 수보다 작게 설정할 수 없습니다.

도시 목록 GUI에서 직접 관리할 수 있는 관리자 기능은 추후 추가할 예정입니다.

## 주민 강화

일부 주민은 앞으로 Altar에서 얻을 수 있는 전용 아이템을 사용해 특수 주민으로 강화할 수 있도록 설계할 예정입니다.

강화된 주민은 기존 거래 화면 대신 기능에 맞는 커스텀 GUI를 사용하도록 구성합니다.

계획 중인 강화 주민은 다음과 같습니다.

| 주민 | 기능 |
| --- | --- |
| 명칭 미정 | 건축 아이템 복사 |
| 명칭 미정 | 아이템 자동 정리 |
| 명칭 미정 | 아이템 자동 굽기 |

주민 강화는 도시 탐험에서 얻은 보상을 실제 생활 및 건축 편의 기능으로 연결하는 역할을 합니다.

## 커스텀 프로필

플레이어의 주요 정보를 한 화면에서 확인할 수 있는 프로필 시스템을 추가할 예정입니다.

프로필에서는 다음 정보를 확인할 수 있도록 구성할 예정입니다.

- 최근 접속 시간
- 레벨
- 인벤토리
- 발전 과제

기존 발전 과제 화면에 사용되던 `L` 키는 자신의 프로필을 여는 키로 변경하고, 발전 과제는 프로필 내부에서 함께 확인할 수 있도록 구성할 예정입니다.

다른 플레이어의 프로필은 대상 플레이어를 직접 선택하거나 명령어로 대상을 지정해 확인할 수 있도록 설계할 예정입니다.

## 개인 공간

각 플레이어에게 실제 생존 월드와 분리된 개인 건축 공간을 제공할 예정입니다.

개인 공간에서는 기본적으로 크리에이티브 모드를 사용하며, 실제 자원을 소비하지 않고 원하는 건축물을 미리 설계하고 시험할 수 있도록 구성할 예정입니다.

### 건축 도안

개인 공간에서 만든 건축물은 도안으로 저장하고 실제 월드에서 불러올 수 있도록 설계할 예정입니다.

도안을 불러오면 실제 블록을 생성하는 대신 건축물이 반투명한 가이드라인 형태로 표시됩니다.

- 도안은 불러온 플레이어에게만 표시됩니다.
- 다른 플레이어에게는 보이지 않습니다.
- 플레이어는 가이드라인을 따라 실제 블록을 배치할 수 있습니다.

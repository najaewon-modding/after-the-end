# After the End - Season 0

**After the End**는 엔더 드래곤 처치 이후의 플레이를 장기적인 진행 요소로 확장하는 Minecraft NeoForge 모드입니다.

Season 0에서는 도시 해금과 Altar 탐험을 중심으로 새로운 지역을 순차적으로 개방하고, Altar에서 얻는 보상을 이후 주민 강화와 생활 편의 기능으로 연결하는 포스트-엔드 진행 구조를 목표로 합니다.

## 개발 환경

- **Minecraft:** 26.1.2
- **NeoForge:** 26.1.2.97
- **Java:** 25
- **Mod Name:** After the End
- **Mod ID:** `njw_after_the_end`
- **Version:** `1.0.0-mc26.1.2`
- **필수 모드:** `Just Dragon Eggs`

## Season 0 핵심 구조

현재 구현된 기본 진행 구조는 다음과 같습니다.

`엔더 드래곤 처치 → End 탐험 → 공명 수정 제작 → Altar 발견 및 활성화 → 다음 도시 해금 → 새로운 도시 탐험 → Altar 보상 획득`

## 도시 시스템

### 도시 영역

각 도시는 오버월드와 네더의 대응 영역을 하나의 도시 단위로 관리합니다.

해금된 도시 영역에서는 정상적으로 활동할 수 있지만, 오버월드와 네더의 해금되지 않은 영역에서는 주요 상호작용이 제한됩니다.

현재 다음 기능이 적용되어 있습니다.

- 여러 도시와 해금 상태 관리
- 오버월드와 네더의 대응 도시 영역 관리
- 도시 밖 블록 설치 및 파괴 제한
- 도시 밖 블록 및 엔티티 상호작용 제한
- 도시 밖 아이템 및 경험치 획득 제한
- 경계 밖 체류 시 경고 후 마지막 정상 위치로 복귀
- 반투명 도시 경계 표시
- 도시 상태와 마지막 정상 위치 저장

### 시작 도시와 월드 생성

싱글플레이 월드 생성 화면에서 시드를 직접 입력하지 않으면, 시작 도시 안에서 기본 게임 진행에 필요한 Stronghold와 Nether Fortress를 이용할 수 있는 시드를 자동으로 탐색합니다.

시드를 직접 지정하거나 전용 서버에서 월드를 생성하는 경우에는 이 자동 탐색이 적용되지 않으며, 현재는 시작 도시 안에 두 구조물이 존재하도록 별도로 보정하지 않습니다.

오버월드에서 엔더의 눈을 사용하면 시작 도시 안에 있는 Stronghold를 향하도록 동작합니다.

### 해금 대기 도시

처음부터 모든 도시를 이용할 수 있는 것은 아닙니다.

월드에는 다음 해금을 위한 도시가 미리 준비되며, 항상 3개의 해금 대기 도시가 유지됩니다. 도시 하나가 해금되면 새로운 해금 대기 도시가 추가로 준비됩니다.

도시 목록에는 모든 해금 대기 도시가 표시되지 않고, 현재 다음으로 해금할 수 있는 도시 하나만 표시됩니다.

### 도시 목록과 이동

기본 `C` 키를 눌러 도시 목록을 열 수 있습니다. 키 설정은 Minecraft 조작 설정에서 변경할 수 있습니다.

도시 목록에서는 현재 확인 가능한 도시와 해금 상태를 확인할 수 있으며, 도시 이름을 더블클릭하여 이름을 변경할 수 있습니다.

도시 이동 규칙은 다음과 같습니다.

- 현재 도시보다 상위 도시로 이동하려면 활성화된 Altar 근처에 있어야 합니다.
- 현재 도시보다 하위 도시로 이동하는 경우에는 Altar가 없어도 이동할 수 있습니다.
- 이동 준비 시간은 8초입니다.
- 이동 중 움직이거나 피해를 받거나 주변에 수면을 방해하는 적대적 몹이 있으면 이동이 취소됩니다.
- 이동 완료 후 다시 도시 이동을 사용할 수 있기까지 5초의 쿨타임이 적용됩니다.
- 활성화된 Altar 근처에서 `V` 키를 누르면 해당 Altar를 그 도시의 도착 지점으로 설정할 수 있습니다.

## Altar

각 도시에는 탐험을 통해 발견할 수 있는 여러 Altar가 생성됩니다.

- 한 도시에는 3개에서 8개의 Altar가 생성됩니다.
- Altar는 크기, 색상, 파손 상태 등이 서로 다를 수 있습니다.
- 한 도시에서 활성화할 수 있는 Altar는 최대 3개입니다.
- 활성화된 Altar는 도시 이동 거점과 도착 지점으로 사용할 수 있습니다.
- 한 도시에서 **첫 번째 Altar를 활성화했을 때만** 다음 해금 대기 도시가 열립니다.
- 두 번째와 세 번째 Altar를 활성화해도 추가 도시가 해금되지는 않습니다.

### 공명 수정

Altar 활성화에는 **공명 수정(Resonance Crystal)**이 사용됩니다.

공명 수정은 다음 재료로 제작할 수 있습니다.

- 유리 7개
- 엔더의 눈 1개
- 셜커 코어 1개

셜커 코어는 셜커를 처치하면 획득할 수 있습니다.

공명 수정을 일반 장소에 설치하면 일정 주기로 주변 생명체를 공중부양시키지만, 비활성화된 Altar의 지정된 위치에 설치하면 안정화되어 활성화 의식에 사용할 수 있습니다.

### Altar 활성화

현재 Altar 활성화 의식은 `Just Dragon Eggs`에서 기록된 드래곤 알과 공명 수정 4개를 사용합니다.

Altar 중앙을 기준으로 동, 서, 남, 북의 지정 위치에 공명 수정을 설치하고 중앙에 기록된 드래곤 알을 놓으면 활성화 의식이 시작됩니다.

활성화에 사용한 공명 수정은 소모되며, 기록된 드래곤 알은 의식이 끝난 뒤 다시 회수할 수 있습니다.

### 숨겨진 보상

각 Altar 내부에는 숨겨진 보물 상자가 하나 생성됩니다.

보물 상자에는 오버월드, 네더, End 및 일반 보물 풀에서 선택된 자원과 함께 **알약 7종 중 하나가 무작위로 반드시 포함**됩니다. 일정 확률로 고대 잔해, 위더 스켈레톤 해골, 마법이 부여된 황금 사과와 같은 희귀 보상도 등장할 수 있습니다.

## 알약

현재 알약 7종의 아이템 등록과 Altar 보상 상자를 통한 획득은 구현되어 있습니다. 각 알약은 이후 주민 강화 시스템과 연결되어 다음 기능을 담당하도록 설계되어 있습니다.

| 기능 | 이름 |
| --- | --- |
| 건축 아이템 복사 | **복제 알약** |
| 아이템 자동 정리 | **정리 알약** |
| 아이템 자동 굽기 | **제련 알약** |
| 아이템 자동 보급 | **보급 알약** |
| 자동 양조 및 음식 강화 | **조제 알약** |
| 아이템 배송 & 폐기 | **물류 알약** |
| 인벤토리 프리셋 교체 | **전환 알약** |

현재 단계에서는 알약 자체의 기능 실행과 주민 강화 GUI는 아직 구현 전입니다.

## 가이드 책

접속 시 현재 진행 방식이 정리된 가이드 책을 자동으로 지급할 수 있습니다.

- 클라이언트 언어에 따라 한국어 또는 영어 가이드가 제공됩니다.
- 기존 가이드 책이 있으면 최신 내용으로 교체됩니다.
- 자동 지급 여부는 모드 설정에서 켜거나 끌 수 있습니다.

## 관리자 기능

현재 다음 관리자 명령어를 사용할 수 있습니다.

- `/city create` — 해금된 도시 생성
- `/city unlock <cityId>` — 잠긴 도시 해금
- `/city delete <cityId>` — 도시 삭제
- `/city load <cityId>` — 해당 도시 청크 사전 준비
- `/city list` — 도시 목록 및 상태 확인
- `/city info <cityId>` — 도시 상세 정보 확인
- `/city max` — 최대 해금 도시 수 확인
- `/city max <count>` — 최대 해금 도시 수 설정
- `/altar list` — 현재 위치한 도시의 생성된 Altar 목록 확인

기본 최대 해금 도시 수는 5개입니다. 시작 도시는 삭제할 수 없으며, 플레이어가 내부에 있는 도시는 삭제할 수 없습니다. 최대 도시 수는 현재 해금된 도시 수보다 작게 설정할 수 없습니다.

## 주민 강화

Altar에서 획득한 알약을 이용해 주민을 특수 기능을 제공하는 주민으로 강화하는 시스템을 추가할 예정입니다.

강화된 주민은 일반 거래 화면 대신 기능에 맞는 전용 GUI를 사용하도록 구성할 예정입니다. 알약별 예정 기능은 위의 **알약** 항목을 따릅니다.

## 커스텀 프로필

플레이어의 주요 정보를 한 화면에서 확인할 수 있는 프로필 시스템을 추가할 예정입니다.

프로필에서는 최근 접속 시간, 레벨, 인벤토리, 발전 과제 등을 확인할 수 있도록 구성할 예정입니다.

## 개인 공간과 건축 도안

각 플레이어에게 실제 생존 월드와 분리된 개인 건축 공간을 제공하고, 개인 공간에서 만든 건축물을 도안으로 저장해 실제 월드에서 반투명 가이드라인으로 불러오는 기능을 추가할 예정입니다.
